# RF System Design Journal

**Goal:** Master RF Engineering from First Principles to Industrial BLE Gateway Design.
**Focus:** Mathematics (IQ/FFT), RF Physics (Smith Charts), and BLE Mesh Architecture.

## 📚 16-Week Master Roadmap

### Phase 1: The Mathematician (Signals & Modulation)
- [ ] **Week 1:** Signals & Spectra (FFT, Time-Freq Duality, Harmonics)
- [ ] **Week 2:** Complex Numbers & IQ Modulation (Phasors, Negative Freq)
- [ ] **Week 3:** GFSK Modulation (Gaussian Filtering, BT=0.5, Deviation)
- [ ] **Week 4:** Noise & Sensitivity (Thermal Noise, Noise Figure, BER)

### Phase 2: The Physicist (RF Front-End)
- [ ] **Week 5:** Transmission Lines (Impedance, Reflections, VSWR)
- [ ] **Week 6:** The Smith Chart (Matching Networks, L/Pi Match)
- [ ] **Week 7:** Active RF (LNA, PA, IIP3, P1dB Compression)
- [ ] **Week 8:** Antennas & Propagation (Link Budgets, Path Loss)

### Phase 3: The BLE Architect (System & Mesh)
- [ ] **Week 9:** The Link Layer (Packets, Channels, Hopping/CSA#2)
- [ ] **Week 10:** BLE Mesh (Flooding, Relay/Proxy Roles, Provisioning)
- [ ] **Week 11:** Gateway Interface (HCI Protocol, UART/SPI, Host Stack)
- [ ] **Week 12:** Data Transport (DLMS over BLE, Segmentation/SAR)

### Phase 4: The Expert (Industrialization)
- [ ] **Week 13:** Coexistence (Wi-Fi/LTE Blocking, SAW Filters, PTA)
- [ ] **Week 14:** Manufacturing (Direct Test Mode, XO Trim, Tx Power Cal)
- [ ] **Week 15:** Reliability Automation (Python Scripting, RSSI Heatmaps)
- [ ] **Week 16:** Certification (ETSI EN 300 328, FCC Part 15, RED)
